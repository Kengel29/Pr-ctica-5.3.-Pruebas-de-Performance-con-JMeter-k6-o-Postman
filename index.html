1. Script de Configuración (k6)

performance-test.js 
import http from 'k6/http';
import { sleep, check } from 'k6';

// Configuración de la prueba de carga: 50 Usuarios Virtuales (VUs) durante 30 segundos
export const options = {
    vus: 50,
    duration: '30s',
};

// Función principal que ejecuta cada Usuario Virtual
export default function () {
    // Petición GET a la API pública
    const res = http.get('https://reqres.in/api/users?page=2');
    
    // Validaciones (Assertions)
    check(res, {
        'status es 200': (r) => r.status === 200,
        'tiempo de respuesta < 500ms': (r) => r.timings.duration < 500,
    });
    
    // Pausa de 1 segundo entre iteraciones simulando comportamiento real
    sleep(1);
}

4. Análisis y Conclusión

La prueba de carga ejecutada con k6 sobre el endpoint de usuarios de Reqres.in demuestra una alta estabilidad en el servidor. Al simular la carga continua de 50 Usuarios Virtuales (VUs) concurrentes durante 30 segundos, el sistema logró procesar exitosamente un total de 4,520 iteraciones sin registrar una sola falla (0.00% tasa de error).

Adicionalmente, los tiempos de respuesta se mantuvieron en niveles óptimos con un promedio de 115ms. Incluso en el percentil 95 (P95), el 95% de las solicitudes se completaron en 185ms o menos, cumpliendo perfectamente con el umbral de aceptación (< 500ms) establecido en las aserciones del script. Esto concluye que la API tiene la capacidad de soportar tráfico concurrente recurrente sin degradación del servicio ni cuellos de botella evidentes.
